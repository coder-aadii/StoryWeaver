Regenerate JSON Schema with `make schemas`. When changing the timeline shape, update the Pydantic model, regenerate, update the zod mirror and `packages/video/sample/timeline.json`, and run both test suites ([adding a Remotion composition](../development/adding-a-remotion-composition.md)).

Both sides are checked against the same canonical valid/invalid sample documents in `packages/schemas/samples/` (generated by `make schemas`; `apps/api/tests/test_timeline_contract.py` and `packages/video/src/contract.test.ts`), so a one-sided change fails `make test`. (The Remotion `zod` version mismatch was fixed by pinning `zod` to exactly 4.5.4 in `packages/video` and `apps/web`.)
